  0.  三  十  秒  上  手
══════════════════════════════════════════════════════════════════════════

  ① 确认你有：Minecraft 1.21.11 + Fabric Loader 0.18+ + Meteor Client
  ② 把 yuio-x.x.x.jar 丢进 .minecraft/mods/
  ③ 启动游戏，按 右Shift 打开 Meteor 菜单
  ④ 左边分类里会多出 4 个：Attack / Assist / Other / Settings
  ⑤ 想加 HUD？Meteor 菜单 → HUD → 左侧列表 → 点右上角「+」→ 选 yuio 分类

  完了。就这么简单。

  ⚠ 千万别下文件名里带 -sources 的 jar！那是源码包，扔进 mods 会直接报错。


══════════════════════════════════════════════════════════════════════════
  1.  环  境  要  求  与  安  装
══════════════════════════════════════════════════════════════════════════

  【必须对上，错一个版本都起不来】

      Minecraft .......... 1.21.11         （不是 1.21.8、不是 1.21.10）
      Fabric Loader ....... 0.18 或更高
      Meteor Client ....... 1.21.11-86 或更高
      Java ................ 21             （只有自己编译才需要装）

  【安装三步】

      1. 去 Releases 页面下载 yuio-x.x.x.jar
         https://github.com/wuchuan9178/yuio-client/releases

      2. 把它和 meteor-client-xxx.jar 一起放进：
         C:\Users\你的用户名\AppData\Roaming\.minecraft\mods\
         （正版启动器的话就是这个路径；其他启动器去启动器的「游戏目录」里找 mods 文件夹）

      3. 启动游戏

  【怎么确认装上了】

      进游戏后按 右Shift 打开 Meteor 菜单，
      左边最下面应该能看到 Attack / Assist / Other / Settings 四个分类。
      看不到 → 说明没加载，去第 7 节。

  【文件夹长这样才对】

      mods\
        ├── meteor-client-1.21.11-86.jar
        └── yuio-0.1.0.jar          ← 就是你下的这个

      ❌ 不要解压！不要改成 .zip！不要放进 mods 里的子文件夹！


══════════════════════════════════════════════════════════════════════════
  2.  装  完  第  一  次  进  游  戏  做  什  么
══════════════════════════════════════════════════════════════════════════

  按重要性排序，做完这四步就算配好了。

  ─────────────────────────────────────────────────────────────────────
  第 1 步　把 HUD 放出来
  ─────────────────────────────────────────────────────────────────────

      Meteor 菜单 → HUD（左侧图标）→ 右上角「+」→ 选「yuio」分类

      里面一共 7 个，先加这两个就够用：

        · Dynamic Island  （灵动岛）—— 平时显示客户端/服务器/延迟，放歌变播放器
        · Notify HUD      （通知卡片）—— 模块开关、图腾 pop 都弹在这

      加完在 HUD 编辑器里拖到你喜欢的位置，按 Esc 保存。

  ─────────────────────────────────────────────────────────────────────
  第 2 步　调字体（中文必看！）
  ─────────────────────────────────────────────────────────────────────

      灵动岛、通知、目标 HUD 都有一个 font 设置：

        Game    = 用游戏自带字体   ← 【有中文，默认就是这个，别乱改】
        Meteor  = 用 Meteor 的字体 ← 【没有中文字形！中文会变成空白】

      如果你发现 HUD 上中文全没了 / 只剩方块 → 就是这里被改成 Meteor 了。

  ─────────────────────────────────────────────────────────────────────
  第 3 步　开个自瞄试试手感
  ─────────────────────────────────────────────────────────────────────

      Attack 分类 → AimAssist → 打开

      默认参数就能用，但想调手感看这几个：

        rotation-mode (瞄准方式)
            Server   = 只动服务端，你自己屏幕上看不出在自瞄   ← 低调
            Client   = 连你自己视角一起转                     ← 跟手

        rotation-mode 选了 Client 才有意义 ↓
        smooth-mode (平滑曲线)
            Exponential       = 越接近越慢，最像人手  ← 默认，推荐
            ExponentialPlus   = 更狠一点的指数
            Linear            = 匀速
            Sine              = 正弦缓入缓出
            Instant           = 瞬移，一点都不平滑

        responsiveness = 指数模式的跟手程度（数字越大越快）
        speed          = 线性/正弦模式的速度

        acquire-mode (找谁)
            Auto       = 自动找范围内最近的
            Crosshair  = 准星真的指到实体身上才锁  ← 不会乱锁人

        lock-target    = 打开后认准第一个目标就不换了  ← 打一个追到底
        rotation-mode  = Server / Client（见上）

  ─────────────────────────────────────────────────────────────────────
  第 4 步　把目标 HUD 加上
  ─────────────────────────────────────────────────────────────────────

      同样是 HUD 编辑器里加「Target HUD」。

      加了之后打谁，谁就弹一张卡：
        皮肤头像 ｜ 名字 / 血条（条里写着 当前血量/上限）
                 ｜ 副手 · 黑条 · 四件护甲（灰条分隔） · 黑条 · 主手

      打多个目标会一张一张往下堆，谁刚被打谁在最上面，很久不打自己淡出。
      对面死了会有动画：头像转 20 度淡掉，然后卡里一个字一个字蹦出
      EZZZZZZZZ，最后整张卡慢慢消失。

      没打人的时候在 HUD 编辑器里会显示一张假的「Target」预览卡，
      用来给你调大小和位置——出编辑器就没了，别慌。

      觉得卡片太暗？调 tint-alpha（默认 96），那是压暗蒙版的强度。
      觉得图案不好看？background 可以切 image b / glass。


══════════════════════════════════════════════════════════════════════════
  3.  功  能  速  查
══════════════════════════════════════════════════════════════════════════

  ── HUD（7 个）────────────────────────────────────────────────────────

  Dynamic Island .... 灵动岛。空闲态显示客户端/服务器/延迟/坐标；
                      放歌时整块变成网易云播放器（圆形专辑封面 + 歌名 +
                      歌手 + 实时歌词，太长会左右循环滚动）；
                      长按 Tab 展开玩家列表；还有容器预览、进食进度、
                      QQ 消息、模块开关通知。
                      注意：scale(胶囊大小) 和 font-scale(字体大小)
                            是两个独立参数，别只调一个然后说没变化。

  Notify HUD ........ 通知卡片。圆角 + 半透明图片背景（两套样式可切）
                      + 左上角图标 + 右上时间 + 底部进度条，
                      出现/消失都有动画，多张卡纵向堆叠。
                      同一个模块反复开关只复用一张卡，不会刷屏。
                      ★ 图腾 pop：默认格式 %name% pop %count%，
                        同一个玩家名永远只占一张卡，次数往上累加。

  Target HUD ........ 目标 HUD。见第 2 节第 4 步。

  Image HUD ......... 贴纸 HUD。8 种内置样式 + 自定义图片路径。

  Friend HUD ........ Meteor 好友列表，命中时名字变绿。
                      判定可选「附近 / 同服 / 任意」，别选错了然后说没反应。

  Radar HUD ......... 俯视雷达。自己在正中心，玩家红、好友绿。

  Key List HUD ...... 所有绑了快捷键的模块，左边名字右边按键。

  ── Attack（攻击）─────────────────────────────────────────────────────

  AimAssist ............ 自瞄，见第 2 节第 3 步
  MaceMissAura ......... 锤子，带可加减的 VClip 高度列表
  MaceMissAurav2 ....... 锤子 v2（skid by puerhx(iaa)）
  MaceAura ............. 自动锤击暴击光环
  SpearAura ............ 长矛光环：飞到目标头顶 → 悬停蓄力 → 俯冲穿刺，
                         循环执行，带反拉回保护。
                         打小碰撞箱打不中就把 box-center 打开。
  SpearArmorBreaker .... 长矛破甲
  LacrymiraAura ........ 光环
  AutoElytraMace ....... 鞘翅起飞 + 俯冲 + 锤击一条龙

  ── Assist（辅助）─────────────────────────────────────────────────────

  AutoLandingWater ..... 落地水。下落时自动低头放水、落地后自动收回来，
                         水被冲走了会重新找水源。
  SuperVClip / HorizontalVClip ... 垂直 / 水平穿墙
  AntiLag .............. 抗拉回，把移动包平滑化
  PacketLimiter ........ 发包限速。只按 PPS 算，带白名单
  PacketLimitTester .... 刷垃圾包测服务器上限（别在正式服乱开）
  AntiMiss ............. 锁一个快捷栏槽位放图腾，自动补货
  Orbit ................ 绕圈走位，可只在弹图腾时绕
  TPBot / TP-bot-V2 .... 自动追踪目标
  auto-copy-chat ....... 鼠标悬停到某条聊天消息后 Ctrl+C 复制
  auto-ez .............. 击杀/被击杀猫娘播报，
                         支持 %s 死者 %m 自己 %z 坐标 %c 计数 %p 图腾数

  ── Other（其他）──────────────────────────────────────────────────────

  motion-blur .......... 全局动态模糊。strength 强弱 / max-opacity 混合
                         比例 / sensitivity 跟手程度，
                         only-when-moving 打开后站着不动完全不显示。
  custom-fonts ......... 用 HarmonyOS Sans 换全局字体，6 种字重
  animations ........... 第一人称挥手动画
  totem-particle ....... 改 pop 粒子
  model-replace ........ 把自己替换成原版怪物模型
  smooth-camera ........ 视角更顺滑
  custom-prefix ........ 彩虹流动前缀
  custom-sound-alerts .. 自定义音效提示
  keep-bouncy .......... 附近的生物变得有弹性
  web-gui .............. 浏览器版 ClickGui
  repeater ............. 重复发送聊天消息
  IQ+++ / AutoDick / AutoSex / auto-kouzi ...... 彩蛋，自己点开看

  ── Settings（设置）───────────────────────────────────────────────────

  GlobalSettings ....... 全局设置。TpUtils 的移动距离、速度、分包策略、
                         发包间隔统一收在这里，不用再一个个翻面板
  TP Setting ........... TP 参数（TpUtils / TPUtilX / LTpUtils 三种实现）
  predict-setting ...... 预测相关参数


══════════════════════════════════════════════════════════════════════════
  4.  按  键  与  常  用  操  作
══════════════════════════════════════════════════════════════════════════

  右 Shift ......... 打开/关闭 Meteor 主菜单
  Esc .............. 从 HUD 编辑器返回并保存
  长按 Tab ......... 灵动岛展开玩家列表（如果 tab-mode 不是 replace）

  【HUD 编辑器怎么用】

      加元素：Meteor 菜单 → HUD → 右上角「+」→ 选分类 → 选元素
      移动  ：直接拖
      改大小：拖右下角（有些元素是靠 scale 设置调的，拖不动就去找设置）
      删掉  ：点元素右上角的叉，或者选中后按 Delete
      存盘  ：按 Esc 返回

  【用不了的输入框】

      HUD 元素必须先在编辑器里加出来，游戏里才会渲染。
      只加模块没加 HUD，屏幕上当然是什么都没有的。

  【想给自己模块绑快捷键】

      Meteor 菜单 → 找到模块 → 点右边的「Keybind」→ 按你想绑的键
      绑完可以在 Key List HUD 里一眼看全。

  5.  素  材  替  换（不  用  重  新  打  包）
══════════════════════════════════════════════════════════════════════════

  所有图片都能换。放到游戏目录下这个文件夹里就生效：

      .minecraft\meteor\yuio\
        ├── notify\
        │     ├── background_a.png     通知卡片背景（样式 a）
        │     ├── background_b.png     通知卡片背景（样式 b）
        │     └── icon.png             通知卡片左上角图标
        ├── hud\yuio_client.png        贴纸 HUD（yuio logo 样式）
        ├── dynamic_island\icon.png    灵动岛图标
        ├── gui\singleplayer.png       贴纸 HUD 的内置样式 ……
        └── title_background.png       主界面背景

  【规则（很重要）】

      · 外部文件优先：你放了就用你的
      · 文件不存在 / 读不出来 / 不是有效图片 → 自动回退到内置素材
      · 所以改坏了也不会黑屏，删掉就恢复原版
      · 换完之后不用重启游戏，回主菜单再进一次就行

  【尺寸建议】

      · 通知背景：和卡片比例接近就行，会被拉伸铺满
      · 主界面背景：越大越好，会按真实尺寸采样，不裁不重复
      · 图标：正方形，128×128 或 256×256 就够

  【想换成 GIF / 视频？】

      不支持。只吃静态图片（png / jpg）。

  6.  QQ 消  息  与  网  易  云
══════════════════════════════════════════════════════════════════════════

  ─────────────────────────────────────────────────────────────────────
  QQ 消息
  ─────────────────────────────────────────────────────────────────────

  【什么都不用装】

      不用 NapCat、不用 LLOneBot、不用任何注入插件，
      不占端口、不联外网、不需要管理员权限。

      它是直接读 Windows 的通知数据库，所以：

      ✔ 要求：Windows 10 / 11
      ✔ 要求：QQ 开着，并且系统通知是开着的
      ✔ 开着 QQ 收到消息 → 灵动岛就弹卡片

  【在灵动岛里打开】

      HUD 编辑器 → 选中 Dynamic Island → 找 QQ 那一组设置：

          qq-enabled        开关，默认关，要自己打开
          qq-duration       卡片停留多久（毫秒）
          qq-max            最多叠几张
          qq-account        只显示这个 QQ 号的，留空=所有账号
          qq-only-mention   只显示 @ 我 的
          qq-ignore         忽略列表，填群号或群名，一个一行
          qq-status         数据库读不到时也弹一张卡告诉你，免得你以为它坏了

  【为什么只看到最后一条？】

      Windows 的同一个会话只保留最新一条通知。
      所以有人在一个群里连发五条，你只能看到最后一条。
      这是系统限制，改不了。

  ─────────────────────────────────────────────────────────────────────
  网易云音乐
  ─────────────────────────────────────────────────────────────────────

  【歌名歌手会自动读到】

      它读的是网易云主窗口的标题（格式「歌名 - 歌手」）。
      只要网易云开着放歌，就不用额外配置。

  【想精确同步歌词？多做一步】

      默认情况下它是拿不到真实播放进度的，只能自己估算时钟，
      所以你暂停、拖进度条，歌词会漂。

      想要一点都不漂：

          1. 关掉网易云
          2. 右键网易云的快捷方式 → 属性 → 目标那一栏末尾加：
                 --remote-debugging-port=9222
             注意：横线前面要有个空格
          3. 用这个快捷方式启动网易云
          4. 进游戏，灵动岛的 music-cdp-port 保持 9222

      这样它就能读到页面上的真实播放进度和当前歌词行了，
      暂停、拖动、切歌全都跟得上。

      不想用？把 music-cdp-port 填 0 就关了，不填也没关系。

  【专辑封面】

      自动的。按「歌名 + 歌手」搜，拿到封面图下载下来，
      解码成圆形头像。第一次搜可能慢个一两秒，正常。

  7.  出  问  题  了  ？按  这  个  顺  序  查
══════════════════════════════════════════════════════════════════════════

  ┌────────────────────────────────────────────────────────────────────┐
  │  第 1 步：看版本对不对                                             │
  └────────────────────────────────────────────────────────────────────┘

      MC 必须是 1.21.11，Fabric Loader ≥ 0.18，Meteor ≥ 1.21.11-86。
      90% 的「一进游戏就崩」都是这里对不上。

  ┌────────────────────────────────────────────────────────────────────┐
  │  第 2 步：看有没有装 -sources                                        │
  └────────────────────────────────────────────────────────────────────┘

      mods 文件夹里如果有名字带 -sources 的 jar，删掉。
      那是给开发者看的源码包，不是给游戏用的。

  ┌────────────────────────────────────────────────────────────────────┐
  │  第 3 步：看日志                                                      │
  └────────────────────────────────────────────────────────────────────┘

      位置：.minecraft\logs\latest.log

      在里面对着 Ctrl+F 搜这几个关键词：

          yuio            看有没有加载相关报错
          Caused by       崩溃的原因通常在这行下面
          NoSuchMethod    版本不匹配的典型症状
          ClassNotFound   少了依赖，或者游戏版本不对

      把报错那几行发到群里，比说「我的不能用」有用一万倍。

  ┌────────────────────────────────────────────────────────────────────┐
  │  第 4 步：对着症状找                                            │
  └────────────────────────────────────────────────────────────────────┘

      【Meteor 菜单里没有我的分类】
        → Meteor 版本低于 1.21.11-86，或者 yuio 根本没加载（看第 3 步）

      【HUD 里找不到 yuio 分类】
        → 编辑器里要往最下面滚，分类是按名字排序的

      【加了 HUD 但屏幕上没有】
        → 检查元素是不是被拖出屏幕了；或者 isActive 没打开

      【HUD 上中文变成空白 / 方块】
        → 那个元素的 font 被改成 Meteor 了，改回 Game

      【在 HUD 编辑器里点「添加目标 HUD」客户端崩溃】
        → 老版本的问题，已经修了，更新到最新 jar

      【qq 卡片一直不出现】
        → qq-enabled 没开；或者 Windows 通知被关了（设置 → 系统 →
          通知 → 允许通知）；或者那个群被免打扰了

      【放歌但灵动岛不变播放器】
        → 网易云主窗口标题必须是「歌名 - 歌手」格式；
          有些版本的网易云标题不一样，这时候读不到

      【歌词会漂】
        → 正常的，见第 6 节，加 --remote-debugging-port=9222 就不漂了

      【落地水放下去又收不回来】
        → 老版本问题，已修，更新

      【用了 Mace 模块在空中跟人对拼被摔死】
        → 打开模块里的 no-ground

      【一开某个模块就被服务器踢】
        → 那是模块特性，不是 bug。开之前想想后果

  ┌────────────────────────────────────────────────────────────────────┐
  │  第 5 步：还是不行                                                    │
  └────────────────────────────────────────────────────────────────────┘

      把这三样发到群里：
        ① Minecraft 和 Meteor 的确切版本号
        ② latest.log 里的报错（不要截图整个日志，就那几行）
        ③ 你做了什么操作之后出现的

  8.  常  见  问  题  F A Q
══════════════════════════════════════════════════════════════════════════

  Q: 要钱吗？有验证吗？
  A: 不要钱，没验证，不联网校验，不收集任何东西。纯公益。

  Q: 混淆过吗？
  A: 没有，源码就在 GitHub 上。

  Q: 支持 1.21.8 / 1.21.10 吗？
  A: 不支持。只做 1.21.11。别的版本会报 NoSuchMethod。

  Q: 有 Forge / NeoForge 版吗？
  A: 没有。这是 Meteor Client 的扩展，必须是 Fabric。

  Q: 能和朋友一起用吗？
  A: 能用哪用哪。但请先看清楚第 9 节。

  Q: 为什么我的 HUD 和截图里长得不一样？
  A: HUD 全部可调。颜色、大小、圆角、背景图、字体都是设置项，
     自己调成喜欢的就行。

  Q: 我想自己改代码 / 编译。
  A: 克隆仓库，JDK 21，然后：

         git clone https://github.com/wuchuan9178/yuio-client.git
         cd yuio-client
         ./gradlew build

     产物在 build/libs/yuio-x.x.x.jar

  Q: 能提功能需求吗？
  A: 能，群里说。描述得越具体越可能实现。

  Q: 会一直更新吗？
  A: 会跟着 Meteor 和 Minecraft 的版本走。
